# Oxide Keyboard Shortcuts Reference (VS Code Compatible)

Oxide provides an ergonomic, 100% VS Code compatible default keybinding configuration.

## General & Navigation

| Keybinding | Action | Category |
| :--- | :--- | :--- |
| `Ctrl+Shift+P` / `F1` | Open Command Palette | View |
| `Ctrl+P` | Quick Open, Go to File | Go |
| `Ctrl+B` | Toggle Primary Side Bar | View |
| `Ctrl+\`` | Toggle Integrated Terminal | View |
| `Ctrl+\` | Split Editor | View |
| `Ctrl+Shift+M` | Toggle Problems & Diagnostics Panel | View |
| `Ctrl+=` | Zoom In UI Scale | View |
| `Ctrl+-` | Zoom Out UI Scale | View |

## File Operations

| Keybinding | Action | Category |
| :--- | :--- | :--- |
| `Ctrl+N` | New Untitled File | File |
| `Ctrl+O` | Open File Dialog | File |
| `Ctrl+S` | Save Active Document (Atomic Write) | File |
| `Ctrl+Shift+S` | Save As... | File |
| `Ctrl+W` | Close Active Tab | File |

## Editing & Multi-Cursor

| Keybinding | Action | Category |
| :--- | :--- | :--- |
| `Ctrl+Z` | Undo | Edit |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Redo | Edit |
| `Ctrl+X` | Cut Selection (or Current Line) | Edit |
| `Ctrl+C` | Copy Selection (or Current Line) | Edit |
| `Ctrl+V` | Paste Clipboard Contents | Edit |
| `Ctrl+F` | Find in Document | Edit |
| `Ctrl+H` | Replace in Document | Edit |
| `Ctrl+A` | Select All | Edit |
| `Ctrl+Alt+Up` | Add Cursor Above | Edit |
| `Ctrl+Alt+Down` | Add Cursor Below | Edit |
| `Tab` | Indent / Insert Spaces | Edit |
| `Shift+Tab` | Unindent / Dedent | Edit |
| `Ctrl+Shift+[` | Fold Code Region | Editor |
| `Ctrl+Shift+]` | Unfold Code Region | Editor |
